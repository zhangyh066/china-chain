# 筛选标准：哪些公司进「产业链图谱」

> 这份文档记录**筛选规则**、**实测数字**和**验证方式**。
> 规则本身写在 `pipeline/chain_concepts.py`，可自由增删。

## 为什么需要筛选

A 股全市场 5918 家（申万一级口径 5218 家）。如果全塞进图谱：

- **一大半和产业链无关**——银行、券商、地产、交运、零售、传媒、教育、旅游。它们不向谁供货、也不从谁进货，在图上只能是孤点
- 即便只看制造业，行业内部也有大量**没有产业链位置**的公司（贸易商、经销商、业务庞杂的控股平台）
- 孤点占比过高，图就不是图，是通讯录

**目标不是"越大越全"，而是"画出来的每根线都有意义"。**

---

## 三条判据（依次收窄）

### 判据一：B2B 属性 —— 最本质，但数据难拿

图谱的边是"企业 → 企业"。纯 B2C 公司只进货、不供货给其他上市公司，
在图上必然是叶子。判据是：**这家公司卖的东西，主要卖给企业还是消费者。**

- 落地方式：年报披露的「前五大客户占比」，或退回用行业代理
- 现状：客户数据批量拿不到，**本轮先不用这条**

### 判据二：产业链位置 —— 按申万一级行业剔

**保留**（19 个）：机械设备、电子、医药生物、基础化工、电力设备、计算机、汽车、
轻工制造、有色金属、国防军工、食品饮料、通信、纺织服饰、农林牧渔、家用电器、
建筑材料、石油石化、钢铁、煤炭

**剔除**（7 个）：银行、非银金融、房地产、交通运输、商贸零售、社会服务、传媒

**边界**（5 个，需逐条判断）：环保、公用事业、美容护理、建筑装饰、综合

### 判据三：能不能归入某个「产业链环节」

只有落在**具体产业链环节**里的公司才算相关。环节用什么界定：
**经过人工审核的产业链概念板块**（`pipeline/chain_concepts.py`，181 个）。

审核规则一句话：**板块名描述的是"能造出来的东西"，且横跨多个环节。**

| | 例子 | 收不收 |
|---|---|---|
| 收 | 锂电池概念、光伏概念、半导体概念、光刻胶、汽车热管理、稀土永磁 | ✅ 一个板块横跨材料↔零部件↔设备↔终端，公司间真有生意往来 |
| 不收 | 元宇宙概念、拼多多概念、彩票概念 | ❌ 题材炒作 |
| 不收 | 破净股、昨日涨停、大盘成长、MSCI中国 | ❌ 资金面 / 风格 |
| 不收 | 雄安新区、海南自贸、成渝特区 | ❌ 地域概念 |
| 不收 | 白酒、啤酒、调味品、猪肉 | ❌ **同业不算**——里面全是竞争对手，彼此没有供货关系 |

### 判据四：图上有没有连接 —— 剔孤点

建完关系图后，只保留**连接数 ≥ 2** 的公司（至少得和两家同环节公司共现）。

## 怎么验证规则是合理的（关键）

规则定完不能就算完了，**要用图上指标反证**。三个可实测的指标：

| 指标 | 合理区间 | 不达标说明什么 |
|---|---|---|
| **孤立点比例** | < 10% | 还有三成孤点 → 判据三筛得不够 |
| **平均连接数** | 3 – 8 | 太低 = 图太散，像通讯录；太高 = 边太滥，像毛线团 |
| **剔除率** | 记录在案 | 剔了多少、按哪条规则剔的，逐家能说清 |

规则定完先跑一遍看指标，不对就调规则——比一次定死靠谱。

### 验证指标（实测，合格线是自己定的）

| 指标 | 实测 | 合格线 | 判定 |
|---|---|---|---|
| 孤立点比例 | **0.0%** | < 10% | ✓ |
| 每家所属环节数（二分图连接数） | **4.6** | 3–8 | ✓ |
| 行业内平均连接数（完全图口径） | 148 | 3–8 | ✗ |

### ⚠️ 三条必须记住的结论

**① 边模型必须画成二分图。**
"同属一个概念"是完全图（半导体概念里 200 家两两相连），所以公司间平均连接数会爆到 148。
改成 **公司 ↔ 产业链环节节点** 后，每家连 4.6 个环节节点，正好落在合理区间。
**图不是"公司连公司"，是"公司连它所属的环节"。**

**② 判据三是最有效的一条。**
只过判据二时孤立点占 21%；叠加判据三后降到 0–1%。真正筛掉"在行业内但没有产业链位置"的是判据三。

**③ 抽查是必须的——它抓出了白名单的漏洞。**
按行业算判据三剔除率，一眼就能看出哪里不对：

| 行业 | v1 | v3 | 解读 |
|---|---|---|---|
| 电子 / 电力设备 | 3% | **2%** | 主要制造业覆盖很好 ✓ |
| 有色金属 / 计算机 | 5% / 6% | **3% / 3%** | ✓ |
| 医药生物 | 8% | **5%** | ✓ |
| 机械设备 | 18% | **12%** | 补档后明显改善 |
| 基础化工 | 19% | **13%** | ✓ |
| 汽车 | 28% | **24%** | 仍有缺口（见下） |
| 食品饮料 / 农林牧渔 / 纺织服饰 | 96% / 73% / 67% | **87% / — / 66%** | **符合设计**：这些行业主体是 B2C 品类，白名单故意不收（同业不是产业链） |

**抽查抓到的具体误杀**：
- **宇树科技（688836，人形机器人）** → 根因是我写白名单时漏了"机器人一族"，**已补，现在正常入图**
- 贵州轮胎、瑞立科密（汽车制动）、钱江摩托 → **东财概念板块里根本没有"轮胎/汽车制动/摩托车"这些环节**，属数据源本身的缺口

## 已知缺口与两条可选路线

### 缺口
**通用零部件与细分品类的环节在概念板块里不存在**：轮胎、轴承、液压、铸造、锻造、模具、刀具 —— 这些公司在概念体系里没有落点，会被判据三误杀。

### 路线 A：维持现状（已可交付）
- 概念板块 185 个，入图 3889 家，指标全达标
- 语义：**"同属一条产业链"**（能串起跨环节的链条，如苹果概念横跨元件→模组→组装）
- 代价：上述细分品类的公司缺失

### 路线 B：改用/叠加申万三级行业（更官方，但要 237 次请求）
申万三级是**完整的产业链环节体系**，实测包含：
`其他汽车零部件` `消费电子零部件及组装` `家电零部件Ⅲ` `风电零部件` `机床工具`
`纯碱` `氯碱` `钛白粉` `涂料油墨` `氟化工` `聚氨酯` `有机硅` `涤纶` `粘胶` `氨纶`
`锦纶` `改性塑料` `合成树脂` `膜材料` `炭黑` `橡胶助剂` `氮肥` `钾肥` `复合肥`
`生猪养殖` `肉鸡养殖` `宠物食品` `铁矿石` `长材` `板材` `钢铁管材` `磁性材料` …

- **优点**：官方标准、无题材噪声、**100% 覆盖**、精准到环节（平均每个环节 22 家，fan-out 正好）
- **代价**：需要 237 次请求（已抓的 31 个一级别浪费）；且因为 100% 覆盖，**判据三失去筛选作用**，只能靠判据二（剔除服务类三级行业）来筛
- 与路线 A 的关系：**互补**——三级行业答"我在哪个环节"，概念板块答"我在哪条链上"

### 我的建议
**先按路线 A 把产品做出来**（数据已就绪、指标达标），把三级行业作为下一轮增强。
理由：路线 B 多花 237 次请求，换来的是"补齐少数细分品类"和"更精确的环节定位"，
但现在还不知道前端要什么形态——先做出来看到实物，再决定值不值得加。
