## 测试抓出并修复的真实缺陷（节选）
1. **五列被 flex 压扁**（`.vcm-col` 默认可收缩）→ 加 `flex: none`
2. **价格与市值不自洽** → 改为"先定市值，按总股本反推股价"
3. **市值抽样失真** → 对数均匀抽样，中位数回落合理区间
4. **hero 还原按钮失效**：还原触发的 scroll 事件又把 hero 判成"已滚过"
   → 判据从 scroll 监听换成 `IntersectionObserver`
5. **缩放 transform-origin 挂错层级** → 地图顶部空出 157px 且底部溢出
6. **二级连接线被卡片遮挡** → 改连到自己的一级父分组（数据层加 `via` 字段）
7. **图例"实色=可见"语义混淆** → 拆分为"可见=浅色 / 已筛掉=压暗"
8. **行业色与下游古铜撞色**（ΔE 6.7）→ 把"避开已占用语义色"写进配色目标函数
9. **环首尾行业色相相同** → 优化起点，相邻最小色相差 0° → 50.1°
10. **3,749 家公司各产生一次 404** → 用 `index.json` 的 `curated` 标记预判，不发请求
11. **`loadGraph()` 只存 promise 没存结果** → 页面看着正常但内容永久空白，
    最难发现的一类
12. **同一家公司同时出现在对方上下游** → 方向裁决（证据数 → 环节精确度 → 平手放弃）
13. **顶栏搜索无跳转** → 改为候选 + 回车/点击直达公司页
