## 三层语义配色

| 层 | 颜色 | 说明 |
|---|---|---|
| 纸与墨 | 米白 `#F5F3EE` / 墨 `#14181D` | 固定 |
| 主色（链接 / 按钮 / 选中态） | 藏青 `#13375E`（可切松绿 / 石墨） | 可切换 |
| 点睛金 | `#A8863F`（细线 `#E0D3B4`） | 固定 |
| 价格涨跌 | 涨红 `#AE2A1E` / 跌绿 `#0E6B4A` | 固定（A 股惯例） |
| 产业链方向 | 上游藏青 `#1D4E7C` / 下游古铜 `#9C5A2C` | 固定 |
| 行业分类 | 11 色（见下） | 固定 |

**铁律：同一颜色不承担两件事。** 涨跌 / 链条方向 / 行业分类三套语义即使同屏出现也不重叠，
这一点由配色搜索的目标函数保证，而非靠自觉。

「下游古铜」指 `#9C5A2C` 这类深棕铜，只用于数据元素（节点左边框、列色带、连接线），
面积极小。曾尝试把整页底色改为浅古铜，因大面积铺开只剩"旧黄"观感而被否——
教训是：**判断颜色方向要先看大面积实拍，再谈精修**。被否方案的对比度核算脚本保留在
`pipeline/bronze_check.py`（通用 WCAG 对比度检查器，换任何底色都可用）。

## 行业色的搜索优化

11 个行业色由 `pipeline/palette_search.py` 在"低饱和 + 中间明度（L\* 33–64）"约束空间内
爬山搜索得出，目标函数同时要求：

1. 两两色差尽量大（正常视觉 / 红色盲 / 绿色盲三种条件下都要）；
2. 避开已占用的语义色（上游藏青、下游古铜），避免"一色两义"；
3. 保持哑光感（惩罚过饱和与过亮）。

实测（`pipeline/palette_check.py` 可复跑）：

| 指标 | 参考站原配色 | 本项目 |
|---|---|---|
| 正常视觉最小色差 | ΔE 22.6 | **ΔE 26.1** |
| 红色盲最小色差 | ΔE 9.2 | **ΔE 10.6** |
| 绿色盲最小色差 | ΔE 18.0 | ΔE 13.1 |
| 与链条墨色的最小距离 | — | **ΔE 16.0**（无冲突） |
| 环上相邻行业最小色相差 | — | **50.1°**（扇区边界清晰） |

> 色盲模拟采用 Viénot 型 LMS 线性变换，色差为 CIE76——近似值，
> 足以判断"能否区分"，非严格色度学研究。

## 版式细节

让版面"像报告而不像应用"的处理：

- 圆角从 12px 收到 6px——"报告"与"网页应用"最易分辨的一处
- 层次靠细线和留白，不靠投影（仅保留一层极淡的"贴纸"实感）
- 数字等宽对齐（`font-variant-numeric: tabular-nums`）
- 金色细线做栏目分隔（顶栏上沿、区块标题上方）
- 卡片 hover 只变边框，不做"上浮"——那是应用的动作
- Canvas 直接读 CSS 变量取墨色，避免 JS 与样式各抄一份色值
- 换底色必须回头检查"无自有底板"的容器（价值链地图曾因此"漏底"）
- 开发服务器必须发 `Cache-Control: no-store`（`python -m http.server` 不发，
  浏览器按启发式缓存，改完代码刷新仍是旧页面且零报错）

## 参考站设计模式的沿用

项目参照 *Fundamental — Cross-Border Supply Chain Tracker* 的设计模式（非代码）：

1. **构建期干重活，运行期只读 JSON**——所有推导在 pipeline 完成，前端只"读 JSON + 画图"，
   这是零框架的前提
2. **数据按变化节奏切文件**——目录 / 结构 / 行情分离，避免改一个股价重建全部文件
3. **每一层数据都可失败**——行情缺失返回空对象，卡片照常渲染
4. **手写 hash 路由 + 三个保护**——旧路由兼容、异步渲染竞态保护、手动滚动恢复
5. **加载细线的工程化**——深度计数（嵌套不闪）+ 350ms 门闸 + WAAPI `.finished` 收尾
6. **Canvas 固定种子随机**——每次刷新布局一致，图表才有"地图"的意义；
   行业弧段按连接度数排序，hub 居中、连线更短
7. **主题不闪**——首屏绘制前内联脚本把主色打到 `<html>` 上
8. **加语言零代码改动**——丢一个 `locales/xx.json` + manifest 加一行；
   `t(key, fallback)` 双层兜底

## 与参考站的差异（A 股适配）

| 维度 | 参考站 | 本项目 |
|---|---|---|
| 市场 | 标普 500 / 11 个 GICS 行业 | A 股 4,071 家 / 24 个申万一级行业 / 199 个产业链环节 |
| 涨跌配色 | 绿涨红跌（欧美惯例） | 涨红跌绿（A 股惯例，固定不随主题变） |
| 货币 | 多币种 | 人民币（¥ / 亿 / 万亿） |
| 产业链颜色 | 绿=上游、陶土=下游 | 藏青=上游、古铜=下游（红绿让给涨跌，三套语义不重叠） |
| 首页组织 | A–Z 字母导航 | 24 张行业概览卡 + 独立行业页 |
| 术语 / 字体 | 英文优先，Google Fonts | 中文优先，全部本地字体，不依赖网络 |
| 交互式图谱 | 开屏 + 环 + 力导向星系 | 24 张行业小图（环节↔公司二分结构）+ 单行业大图 |
