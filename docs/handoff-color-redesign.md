# 配色改版交接文件：从「橄榄绿 + 土金」到「纸墨藏青」

> 写给执行改动的模型/开发者。本文档包含：诊断、设计决策、**逐行精确的替换清单**、验证步骤。
> 按清单改即可，不需要再做设计决策。所有行号基于当前版本，改之前请先 Read 对应文件核对上下文。

---

## 1. 背景与诊断

这是一个 A 股产业链图谱站点（单页应用 `index.html` + `app.js` + `styles.css`，另有静态 SEO 页 `pages/`）。
用户反馈：「一会儿橄榄绿，一会儿屎黄色，不符合审美」。

经逐页截图走查，问题颜色的确切来源是：

| 用户看到的 | 代码里的值 | 位置 |
|---|---|---|
| 橄榄绿（按钮、选中态、链接、圆饼扇区） | `#1E4A3C` 松绿（默认主色）、`#5B8448` 数据绿 | `styles.css:32`、`app.js:1976` |
| 屎黄色（圆饼扇区、顶部金线、警示框、星标、徽章） | `#996600` 数据金、`#A8863F` 金、`#F2EBD9` 金底 | `app.js:1976`、`styles.css:37-40` |
| 深棕 | `#3F3A33` | `app.js:1976` |

**保留不动**（这些是语义色，不是装饰色，动了会破坏信息表达）：

- 涨红 `#AE2A1E` / 跌绿 `#0E6B4A`（A 股惯例，`--rise` / `--fall`）
- 上游藏青蓝 `#1D4E7C/#3E6E9C`、下游古铜 `#9C5A2C/#7C4520`（价值链地图的方向语义，`--up1/--up2/--dn1/--dn2`）
- 米白纸底 `#F5F3EE`、墨色 `#14181D`（这套"纸与墨"基底是好的，是站点气质的来源）

## 2. 设计方向（已定，勿再发散）

**「纸墨藏青」：暖纸 + 墨 + 唯一的藏青强调色，彻底删除金色通道和橄榄绿。**

原则（来自本站 `styles.css` 开头已有的设计哲学，本次只是把它贯彻到底）：

- 像一份印刷的研究报告，不像数据可视化库的默认盘；
- "fewer hues, more shades"——少色相、多档位；
- 一个颜色只表达一件事：红绿归涨跌、蓝/古铜归上下游、藏青归交互与强调；
- 点缀不靠第二种彩色，靠留白、细线和字重。

新强调色选择 **藏青 `#13375E`** 的理由：

1. 代码里它已经是现成的备选主题（`styles.css:77-81` 的 `[data-accent="navy"]`），对比度、深浅色阶都配好了；
2. `manifest.webmanifest:10` 和 `index.html:20` 的 `theme_color` 本来就是 `#13375E`——浏览器地址栏/图标底色早已是藏青，页面主色却一直不是，这次顺手统一；
3. 藏青在米白纸底上是"机构感"，不是"脏蓝"（值够深、够冷）；
4. 与语义色不冲突：离涨红/跌绿很远；与上游蓝 `#1D4E7C` 同族但明度差一档（藏青做实心节点、上游蓝只做浅色填充和文字，不混）。

金色通道不新增替代彩色，**映射到藏青色系和中性灰**：金的"点睛"职能由藏青接管，金的"细线"职能由中性暖灰接管。

## 3. 精确替换清单

### 3.1 `styles.css` —— 改 8 个 token 的值（不改任何选择器）

`:root` 块内（当前第 32-40 行），**只改值、不改变量名**，这样全表 20 多处 `var(--gold…)` 引用自动生效：

```
--primary:       #1E4A3C  →  #13375E
--primary-dark:  #143528  →  #0B2440
--primary-soft:  #E0EAE5  →  #E2E9F1
--gold:          #A8863F  →  #13375E
--gold-dark:     #836729  →  #0B2440
--gold-soft:     #F2EBD9  →  #E8ECF2
--gold-line:     #E0D3B4  →  #D9D5CB
```

同时更新 `styles.css:29-36` 附近的注释：把「默认主色改成松绿……藏青降为可选项」那段改为「默认主色为藏青；金色通道已废弃，--gold* 是藏青/中性灰的历史别名，仅为兼容旧引用保留」。

`:root[data-accent="forest"]`（当前不存在，需要**新增**，因为旧默认松绿降级为可选项）：

```css
:root[data-accent="forest"] {
  --primary: #1E4A3C;
  --primary-dark: #143528;
  --primary-soft: #E0EAE5;
}
```

放在现有 `:root[data-accent="navy"]`（第 77-81 行）旁边即可。`[data-accent="navy"]` 那组值与新的 `:root` 默认相同，留着无害（也可删，但留着能让"藏青"选项在设置里逻辑简单）。

### 3.2 `app.js` —— 4 处

**① 默认主色（第 94 行）：**

```
accent: "forest",  →  accent: "navy",
```

注释同步改为 `// navy（默认）| forest | graphite`。注意 `applyAccent()`（第 108-112 行）的逻辑是"非 navy 才打 `data-accent` 属性"——改完默认值后逻辑自洽：默认藏青 → 无属性 → 命中 `:root` 新藏青；选松绿 → `data-accent="forest"` → 命中 3.1 新增的那组。

**② 圆饼数据色（第 1976-1977 行）** —— 这是"橄榄绿 + 屎黄"圆饼的直接来源：

```
PART_CYCLE = ["#5B8448", "#996600", "#3F3A33"]  →  ["#1C3A5E", "#7A8CA3", "#3A3F45"]
PART_OTHER = "#BFB6A4"                           →  "#CBC6BC"
```

三个新色分别是：深藏青、灰蓝、炭灰——同族明度阶 + 一个中性锚，相邻扇区一眼可分，且都远离涨红/跌绿。第 1964-1975 行那段关于 FT 绿的长注释已过时，简化为：`// 环节切片：藏青明度阶 + 炭灰锚点，"fewer hues, more shades"；红绿留给涨跌，故此处不含红绿。`

**③ 设置面板色板顺序（第 2953-2957 行）：** 把 navy 排第一并作为默认项即可（数组顺序本来就是 navy 在前，无需改动；确认 `dot` 值 `#13375E` 不变）。

**④ 不需要改**：`OWL_PAL`（第 199 行，中性暖灰，保留）、价值链地图上下游色（第 1386-1391 行，语义色，保留）、`--rise/--fall` 的所有引用（第 768-774、2497-2502 行等）。

### 3.3 `pages/style.css` —— 静态 SEO 页同步（第 2-3 行）

```
--gold: #A8863F        →  #13375E
--gold-line: #E0D3B4   →  #D9D3C4
```

（`--navy: #13375E`、`--paper: #F5F3EE`、`--rise/--fall` 不动。改完后该文件里"金色"实际是藏青，变量名照旧不改，避免动下面 50 行引用。）

### 3.4 其他文件

- `manifest.webmanifest`、`index.html` 的 theme-color 已是 `#13375E`，**不用改**。
- `locales/zh.json`、`locales/en.json` 中 `settings.accent.*` 文案（藏青/松绿/石墨）**不用改**——松绿降级为可选项后名字仍成立。
- `_bak_*.js`、`_bak*.css` 是历史备份，**不要改**。
- `pipeline/palette_check.py` 里的行业 11 色与本次无关，**不要改**。

## 4. 老用户的 localStorage 迁移（可选，建议做）

老用户浏览器里可能存着 `accent: "forest"`。两种处理：

- **简单方案（推荐）**：不管。老用户保留松绿主题，新用户默认藏青。设置里可随时切。
- **彻底方案**：在 `app.js` 读取 settings 后加一行：`if (settings.accent === "forest" && !settings._accentMigrated) { settings.accent = "navy"; settings._accentMigrated = true; saveSettings(); }`。只有产品明确要求"所有人统一新配色"时才做。
